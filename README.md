# Book-My-Show
The project leverages Java Spring Boot, a robust and widely used framework for building enterprise-grade applications, to develop and deploy new features and  improvements to the Book My Show website. Key objectives of the project include optimizing the booking process, improving search functionality, and enhancing overall user experience.
Visitors to the site, once registered, are then able to easily navigate this movie tickets, and buy tickets options with only a few clicks, greatly simplifying the buying process.
